# Portfolio

A personal portfolio site built with [Next.js](https://nextjs.org), TypeScript, and Tailwind CSS.

## Customize your content

Edit **`src/data/portfolio.ts`** — that's the only file you need for name, bio, skills, projects, experience, and social links.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy

Push to GitHub and deploy on [Vercel](https://vercel.com) with one click, or run:

```bash
npm run build
```
